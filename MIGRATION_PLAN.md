# План миграции qyzmeta-bot → smplat

## 📋 Структура проекта

```
smplat/
├── bot/              # Telegram бот (интеграция и уведомления)
├── backend/          # API и бизнес-логика (FastAPI/Flask)
├── frontend/         # Веб-интерфейс (React/Vue)
└── MIGRATION_PLAN.md
```

## 🎨 Фаза 3: Frontend (новый)

**Требования для веб-интерфейса Софтмонтаж:**
- Панель администратора (управление проектами, пользователями)
- Личный кабинет исполнителя (подрядчика)
- Панель клиента (создание заявок, отслеживание статуса)
- Просмотр и редактирование смет/предложений

**Stack:**
- React (TypeScript) / Vue 3
- Vite для сборки
- Zustand/Pinia для состояния
- Axios для API запросов

## 🔧 Фаза 4: Адаптация под Софтмонтаж

### Переименования понятий:
| qyzmeta (ЖКХ) | smplat (слаботочные) |
|---|---|
| JK (многоквартирный дом) | Project (проект монтажа) |
| Resident (жилец) | Client/Customer (клиент) |
| Lot (заявка от жилца) | Task/Request (техническая заявка) |
| Service Provider | Contractor/Executor (подрядчик) |
| Offer (смета) | Quote/Estimate (смета/расчет) |
| Subscription | Tariff Plan (тарифный план) |

### Новые модели для Софтмонтаж:
- `Material` (материалы для проектов)
- `Equipment` (оборудование)
- `ProjectBudget` (бюджет проекта)
- `Contractor` (подрядчик - расширенный ServiceProvider)
