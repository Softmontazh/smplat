🚀 БЫСТРЫЙ СТАРТ (3 ШАГа)

Шаг 1️⃣  - Инициализация (Windows):
  $ init.bat
  
  Или на Linux/Mac:
  $ chmod +x init.sh && ./init.sh

Шаг 2️⃣  - Запуск Backend (в терминале 1):
  $ cd backend
  $ venv\Scripts\activate    (Windows) или source venv/bin/activate (Linux)
  $ uvicorn app.main:app --reload
  
  ✅ Backend доступен: http://localhost:8000
  📚 API docs: http://localhost:8000/docs

Шаг 3️⃣  - Запуск Frontend (в терминале 2):
  $ cd frontend
  $ npm run dev
  
  ✅ Frontend доступен: http://localhost:3000

🎯 ОСНОВНЫЕ МОДЕЛИ

  User (Пользователь)
  ├─ id, telegram_id, email
  ├─ first_name, last_name, phone
  ├─ role (Admin, Manager, Contractor, Client)
  └─ created_at, updated_at

  Project (Проект монтажа)
  ├─ id, name, description
  ├─ address, city, budget
  ├─ owner_id (FK User)
  ├─ status (Planning, InProgress, Completed, Archived)
  └─ created_at, updated_at

  Task (Техническая задача)
  ├─ id, title, description, category
  ├─ owner_id (FK User)
  ├─ project_id (FK Project)
  ├─ priority, status, visibility
  └─ created_at, updated_at

  Quote (Смета/Расценка)
  ├─ id, uuid, title, description
  ├─ task_id (FK Task)
  ├─ contractor_id (FK User)
  ├─ amount, vat, currency
  ├─ status (Draft, Sent, Accepted, Rejected, Expired)
  └─ created_at, updated_at

⚠️  ВАЖНЫЕ ЗАМЕТКИ

  1. ❗ Не забудьте создать БД PostgreSQL:
     $ createdb smplat
  
  2. ❗ Отредактируйте .env файлы с вашими конфигурациями
  
  3. ❗ Установите зависимости перед запуском:
     - Python packages: pip install -r requirements.txt
     - Node packages: npm install
  
  4. ❗ Используйте виртуальные окружения Python:
     - python -m venv venv
     - source venv/bin/activate
  
  5. ❗ Коммитьте изменения часто в Git:
     - git add .
     - git commit -m "description"
     - git push origin main
