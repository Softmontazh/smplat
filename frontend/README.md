# Frontend для проектов Софтмонтаж

## 📋 Описание

Веб-интерфейс для платформы управления проектами слаботочных систем (монтаж, проектирование, продажа).

## 🚀 Быстрый старт

### Установка зависимостей
```bash
npm install
```

### Запуск разработки
```bash
npm run dev
```

Откроется http://localhost:3000

### Сборка для production
```bash
npm run build
```

## 📁 Структура проекта

```
frontend/
├── src/
│   ├── components/          # React компоненты
│   ├── pages/               # Страницы приложения
│   ├── api/                 # API клиент (Axios)
│   ├── store/               # Zustand хранилище состояния
│   ├── types/               # TypeScript типы
│   ├── utils/               # Утилиты
│   ├── App.tsx              # Главное приложение
│   ├── main.tsx             # Точка входа
│   └── index.css            # Глобальные стили
├── package.json
├── vite.config.ts           # Конфиг Vite
├── tsconfig.json
└── README.md
```

## 🎨 Страницы

- **Главная** (`/`) - Информация о компании
- **Панель управления** (`/dashboard`) - Статистика и краткая сводка
- **Задачи** (`/tasks`) - Список задач и создание новых
- **Проекты** (`/projects`) - Управление проектами
- **Сметы** (`/quotes`) - Просмотр и управление сметами

## 🛠️ Инструменты

- **React 18** - UI фреймворк
- **Vite** - Быстрая сборка
- **TypeScript** - Типизация
- **React Router** - Маршрутизация
- **Zustand** - Управление состоянием
- **Axios** - HTTP клиент
- **Tailwind CSS** - Стилизация
- **Date-fns** - Работа с датами
